# Multi-Page Weather App in React

A responsive, client-side Multi-Page Weather Application built with React, React Router, Axios, and Local Storage persistence.

## Features
- **Multi-Page Navigation**: Single-page application routing using React Router (`/`, `/about`, `/contact`).
- **Live Weather Dashboard**: Asynchronous weather data fetching with city selection (`London`, `Tokyo`, `New York`, `Kathmandu`, `Sydney`).
- **Persistent Preferences**: Temperature unit toggle (°C / °F) preserved in Local Storage across sessions.
- **Accessible Contact Form**: Form inputs with explicitly linked label tags.

## Tech Stack
- React.js (Vite)
- React Router DOM
- Axios
- CSS3
